# Tekstark

Lim inn sangtekst, juster oppsettet (papir, kolonner, skrift, størrelse, overskrifter) og last ned som PDF.
Ren HTML/JS uten byggesteg. PDF lages i nettleseren med [jsPDF](https://github.com/parallax/jsPDF) 2.5.1 (MIT), lagt ved i `vendor/`.

Publiseres med GitHub Pages fra `main` / rot.
